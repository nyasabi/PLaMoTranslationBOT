# PLaMo 翻訳BOT ドキュメント

## 概要

国旗の絵文字でリアクションすると、その言語に翻訳して、全員に見える返信として投稿する Discord BOT です。翻訳には PLaMo API（`plamo-3.0-prime`）を使います。

## セットアップ

1. `pip install -r requirements.txt` でライブラリを入れます。
2. `.env.example` を `.env` にコピーし、`DISCORD_TOKEN` と `PLAMO_API_KEY` を設定します。
3. Discord Developer Portal の Bot 設定で **Message Content Intent** をオンにします。
4. 招待時に「チャンネルを見る」「メッセージ履歴を読む」「メッセージを送信」の権限を付けます。
5. `python bot.py` で起動します。ログに `bot version: 4` が出れば成功です。

起動時の `PyNaCl` / `davey` の警告は、ボイス機能用のライブラリがないというだけなので無視して構いません。

## 使い方

翻訳したいメッセージに国旗でリアクションすると、数秒後に翻訳が返信されます。約38か国に対応しています（日本語 🇯🇵、English 🇺🇸 🇬🇧、中国語 🇨🇳 🇹🇼 🇭🇰、韓国語 🇰🇷、フランス語 🇫🇷、ドイツ語 🇩🇪、スペイン語 🇪🇸 など）。全一覧は `bot.py` の `FLAG_LANGUAGES` にあり、国旗・表示名・英語名の1行を足すだけで追加できます。

## 管理コマンド

サーバーの **管理者権限** を持つ人だけが実行できます。それ以外の人が送っても、BOT は反応しません。

| コマンド | 内容 |
| --- | --- |
| `!ping` | Gateway と API の遅延をミリ秒で表示します。 |
| `!t-ban @ユーザー` | そのユーザーの翻訳機能を禁止します。リアクションしても無反応になります。 |
| `!t-unban @ユーザー` | 禁止を解除します。 |

ユーザーIDでも指定できます。禁止はサーバーごとに管理され、`banned_users.json` に保存されます。管理者権限を持つ人と BOT 自身は禁止できません。

## 翻訳の仕組み

原文のまま、または別の言語で返ってきた場合は、自動で再試行します（通常、推論あり、英語経由の順）。すべて失敗したら、「翻訳できませんでした」と通知します。4,000文字を超えるメッセージは翻訳しません。同じメッセージと言語の組み合わせは、重複して翻訳しません。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| リアクションしても反応しない | Message Content Intent がオンか。BOT に履歴を読む権限と送信権限があるか。そのユーザーが `!t-ban` されていないか。 |
| 「翻訳に失敗しました」と出る | ターミナルのスタックトレースを確認します。API キーの誤りや利用上限が多い原因です。また、一時的な問題の可能性もあります。 |
| `!ping` に反応しない | 実行した人がサーバーの管理者権限を持っているか確認します。 |
